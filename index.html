QuizForge stores data in your browser using localStorage for decks/scores and sessionStorage for API keys. API keys are cleared when the tab closes and are only sent directly to the AI provider you choose (Gemini, Anthropic, or Perplexity). QuizForge has no backend.
What's stored locally: quiz decks, scores, missed question lists, and AI-generated explanations in localStorage; API keys in sessionStorage only for the current tab.
What leaves your device: only your PDF (to the AI provider you pick) and API prompts. QuizForge has no backend.
To delete all data: open DevTools → Application → Local Storage and clear the qf_* keys, or use Export Decks before clearing.
